# saysmiledent.github.io

Root address of the GitHub Pages account. It only forwards visitors to the SaySmile site
(https://saysmiledent.github.io/SaySmile/) and holds what search engines read at the root:

- `index.html`: Yandex Webmaster ownership tag, redirect to /SaySmile/
- `robots.txt`: points crawlers to the SaySmile sitemap

The site itself lives in the repository saysmiledent/saysmile.
